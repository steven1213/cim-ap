# IAM-AP 前端设计文档（骨架）

> 本文件为 **骨架占位**，仅记录已确认的架构边界。详细设计待后续按章填充。

## 0. 定位

- **归属**：`docs/business/iam-ap/web/`，基于平台前端框架（`docs/platform/web`）构建，不另起炉灶。
- **职责**：统一登录门户 + IAM 管理后台（应用接入管理、准入分配、粗角色组分配）。
- **不负责**：业务系统的菜单 / 按钮管理 UI —— 由各业务 ap 自己的前端承载。

## 1. 登录门户

- 企业内统一登录页（对接 `iam-ap` 后端，认证源为 LDAP / AD，无三方登录）。
- 登录成功后由 `iam-ap` 后端颁发令牌（含 `apps` / `roles` claim），前端按平台 §3 守卫 + §6 i18n 处理会话。

## 2. 管理后台

- **应用接入管理**：登记 `mds-ap` / `mes-ap` 等 ap 的接入信息（公钥 / scope）。
- **准入分配**：维护用户 ↔ 可进入 ap 的映射（`apps`）。
- **粗角色组分配**：维护用户在某 ap 内的粗分组（如管理员 / 操作员）。
- 仅操作「准入 / 粗角色」维度，**不触碰业务菜单 / 按钮 / 数据权限**。
